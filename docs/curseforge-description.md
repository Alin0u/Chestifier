# Chestifier

Sort, search, and quick-move items between chests, shulker boxes, and your inventory, without digging through slots by hand.

Chestifier is a continuation of [EasierChests](https://www.curseforge.com/minecraft/mc-mods/easierchests) by Giselbaer (gbl), which is end of life and no longer updated. It's built with his blessing to keep the mod alive on current Minecraft versions and add new features.

## What's changed from the original

- Ported to Minecraft 1.21.11
- Added an in-game search box to highlight matching items by name
- Renamed and repackaged under a new author, with an updated icon (also to be compliant)

## Features

- Move a whole row or column of items between your inventory and a chest with one click
- Move all items from your inventory into a chest that already has a matching stack (and back)
- Sort a chest's contents, or your own inventory
- Search box to highlight matching items in a chest by name
- Freeze individual inventory slots (middle-click) so sorting/moving skips them
- Configurable via Mod Menu + Cloth Config
- All actions can be bound to hotkeys

Works on multiplayer servers too, as long as they don't restrict inventory actions via anti-cheat plugins. No server-side plugin required.
